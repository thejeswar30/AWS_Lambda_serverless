01 / INTRODUCTION

What is Serverless Computing?

Serverless computing allows developers to build and run applications without directly managing servers.

⚡

Automatic Scaling

Applications can automatically scale according to incoming requests.

💰

Cost Efficiency

Pay based on resource consumption and configured service pricing.

🛠️

Less Maintenance

AWS manages the underlying server infrastructure.

🔄

Event Driven

Functions execute when events or requests trigger them.

02 / COMPUTE SERVICE

Introducing AWS Lambda

AWS Lambda is a serverless computing service that executes code in response to events without requiring server management.

How Lambda Works

01

Create a Function

Write your application code using a supported runtime.

02

Receive an Event

A request or AWS service event triggers the function.

03

Execute Code

Lambda runs the function to process the incoming event.

04

Return a Response

The function returns the result or sends it to another service.

Supported Runtimes

🟨 Node.js
